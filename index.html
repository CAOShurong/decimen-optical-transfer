DECIMEN — Fountain QR File Transfer (PoC)

Send any file up to 64 MB between two devices using nothing but a screen and a camera. Open send on the device with the file and receive on a phone, then point the phone's camera at the flickering code.

No network path between the devices is used. Files are compressed when that shortens the transfer; the original filename and media type travel inside the fountain stream, and SHA-256 is verified before download.
